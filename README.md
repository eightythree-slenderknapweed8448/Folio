## 📝 How to Use Folio

Folio operates as a simple interface for document conversion. Open the application from your desktop icon or the Start menu. 

### Converting Your First Document

1. Start Folio.
2. Click the "Open" button in the top left corner.
3. Select your Markdown file from your computer.
4. Select a destination folder for your new document.
5. Click the "Convert" button.
6. Wait for the application to notify you of success.
7. Open the folder to view your new Word file.

### Understanding Settings ⚙️

Folio allows minor adjustments to how it creates your files. Click the "Settings" tab to manage these options:

*   Document Template: Choose a base look for your document. If you leave this blank, Folio uses the default clear layout.
*   Heading Styles: Enable this to map your Markdown headings directly to Word's built-in header styles. This makes your table of contents work automatically.
*   Image Quality: Use this to change how images appear in your document. High quality preserves detail but increases file size.

## 🔍 Frequently Asked Questions

Read these answers if you run into trouble during setup or use.

### Why does my document look different?

Folio uses native Word structures. If your Markdown uses special characters, the app converts them into their specific Word equivalents. If your layout looks strange, check if you are using standard Markdown syntax.

### Is Folio safe to use?

Yes. Folio performs all document conversions locally on your computer. Your files never leave your machine during the process. 

### Can I change the default font?

Yes. Go to the Settings tab and select "Advanced." You can pick any font installed on your Windows system. The application applies this font to the body text of your generated Word files.

### Where can I get help? 💬

If you encounter errors, check the log file. You can find this by clicking "Help" and then "View Logs." If you need additional assistance, create a new issue on the GitHub page. Describe the problem clearly to get the best help.

## 📂 Managing Your Files

Folio handles large batches of files well. If you have many Markdown files, you can drag and drop them all at once into the main window. The software processes them one by one. It creates a new folder for your documents so it does not overwrite your original files.

### Maintaining Document Hierarchy

The app respects the structure of your Markdown headers. If you use a Level 1 header in Markdown, Folio creates a Title style. Level 2 becomes a Header 1 in Word. This structure makes your Word documents easy to navigate.
